# Biztonsági keretek

Csak saját gépen futtatható; ne tedd nyilvános hálózatra. .data, .env, ügyféladat és mentés nem commitolható. A JSON mentés személyes adatot tartalmazhat; védd ugyanúgy, mint az adatbázist.

Hiba esetén érzékeny adat nélkül jelezd a repository tulajdonosának. Nyilvános issue-ba ne tegyél ügyféladatot, kulcsot vagy teljes exportot. Sérülékenységnél állítsd le az érintett alkalmazást, őrizd meg a mentést, és frissíts ellenőrzött javításra.
