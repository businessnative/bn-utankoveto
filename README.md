# Utánkövető

Lásd, kinek és mikor esedékes az utánkövetés, és készíts választervezetet.

Add át ezt a repositoryt Codexnek vagy Claude Code-nak, és kérd: **„Építsd meg ezt nekem az én vállalkozásomra. Először olvasd el a START-HERE.md fájlt.”**

## Gyors indítás

Node.js 22.13 vagy újabb szükséges. Nincs telepítendő npm-függőség.

```sh
npm test
npm start
```

Nyisd meg a terminálban kiírt 127.0.0.1 címet. Először állítsd be a vállalkozási profilt. A helyi adatokat a .data könyvtár őrzi.

## Mire képes ez a kiadás?

Lásd docs/CAPABILITIES.md, ezen belül: utankoveto. Ez helyi fejlesztési alap, nem bekötött SaaS. Az automatikus email, nyilvános ügyfélportál és a többfelhasználós hosting nincs aktiválva.

A kiválasztott modul mellett a kapcsolódó érdeklődő- és feladatnyilvántartás is elérhető, ahol szükséges. Minden rekord ugyanabban a helyi munkatérben marad.

## Ellenőrzés és folytatás

EVAL.md: kiadási kapuk. STATUS.md: tényleges készültség. docs/OPERATIONS.md: mentés, működtetés, helyreállítás. docs/ADAPTATION.md: személyre szabás.
